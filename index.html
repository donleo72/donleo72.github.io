Política de Privacidad

Esta aplicación no recoge ni almacena datos personales del usuario de forma directa. Sin embargo, utiliza servicios de terceros que pueden recopilar cierta información con el fin de mostrar publicidad, tal y como se describe a continuación.

Publicidad – Google AdMob

Esta aplicación utiliza Google AdMob para mostrar anuncios. AdMob puede recopilar y usar la siguiente información:

  • Identificador de publicidad del dispositivo (Google Advertising ID)
  • Información del dispositivo (modelo, sistema operativo, idioma)
  • Dirección IP (para geolocalización aproximada)
  • Datos de interacción con los anuncios (impresiones, clics)

Esta información es gestionada exclusivamente por Google y se utiliza para mostrar anuncios relevantes. El usuario puede desactivar la publicidad personalizada en cualquier momento desde los ajustes del dispositivo: Ajustes → Google → Anuncios → Inhabilitar personalización de anuncios.

Para más información sobre cómo Google trata estos datos, consulta la Política de Privacidad de Google.

Datos en el dispositivo

Las preferencias de la aplicación (ajustes de notificaciones) se guardan exclusivamente en el propio dispositivo. En ningún momento se envían a servidores externos ni se comparten con terceros.

Resultados de sorteos

Los resultados que muestra la aplicación se obtienen de fuentes públicas de la ONCE. La app no asocia estos datos a ningún usuario ni registra qué sorteos consulta cada persona.

Notificaciones

Si el usuario activa las notificaciones, estas se envían de forma general a todos los dispositivos suscritos. No se utiliza ningún identificador personal para su envío.
